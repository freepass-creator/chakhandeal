착한거래 플랫폼 정의서 — 브랜드·제품 네이밍 참고

v0.2 · 2026-07-24 · rentsafe-pro · 자기정보 증명 모델

1. 한 줄 정의

내가 쌓은 신뢰를 내가 확인하고, 필요한 상대에게만 직접 증명하는 서비스.

상거래 마켓·결제 중개·블랙리스트 검색 플랫폼이 아닙니다.

비유: 내가 내 당근온도를 열어, 필요한 상대에게만 제출한다.

2. 이중 필터 (동의 → 증명 전달)

  • 1차: 앱에서 착한거래 동의(본인확인) → 안 하면 걸러짐 (낙인 없음)
  • 2차: 사업자 코드 지정 발급(콘솔 수신) + 이용자가 카톡·문자로 링크 전달 → 안 하면 걸러짐
  • 코드 지정 = 해당 사업자 콘솔에 보임 / 카톡·문자 = 외부 전달 채널 (둘의 역할이 다름)

3. 하는 일 / 하지 않는 일

  • 함: 본인확인, 목적별 동의, 본인 증명서 미리보기·건별 제출, 기간 한정 열람, 합의된 이행 사실 기록, 점수/신규 상태, 이의제기
  • 안 함: 이름·전화 검색, 블랙리스트 공유, 주관 별점, 자유 부정 후기, 점수 자동거절, 거래 중개

4. 공통 원칙 (전 업종)

  • 검색 금지 · 본인 주도 제출 · 건별 동의
  • 사실·확정 기록만 · 신규=신규(낮은 점수 아님) · 미제출≠불량 낙인
  • 사람을 보증하지 않음 · 최종 판단은 사업자

4. 버티컬

업종하위브랜드(가칭)증명서이용자→사업자
반려 분양PetSure / 팻슈어책임입양 증명서입양희망자→분양자
렌탈RentSure / 렌탈슈어렌탈 신뢰 검증손님→렌탈사
펜션·숙박StaySure / 스테이슈어숙박 신뢰 증명서투숙객→숙소
식당 예약DineSure / 다인슈어예약 신뢰 증명서예약자→식당

5. 네이밍이 담아야 할 의미

  • 증명 · 확인 · 본인 제출 · 안심 (Deal/Trade/Market 뉘앙스 지양)
  • KYC 대행 회사(SurePass 등)와 혼동 주의
  • 발음 쉬운 영문 + 한국어로 부르기 쉬울 것

6. 네이밍 요청용 문장

업종 공통의 ‘서비스 이용 전 자기신뢰 증명’ 플랫폼 영문 브랜드명을 지어 주세요. 마켓플레이스/결제 앱이 아니고, 타인 검색·블랙리스트 서비스도 아닙니다. 이용자가 본인 증명서를 발급해 특정 상대에게만 제출하는 모델입니다. 하위 브랜드로 PetSure, RentSure, StaySure 확장이 가능해야 합니다.

※ 기존 렌탈 MVP의 “이름+생년월일 조회”는 본 원칙과 충돌 → 검증 링크 제출 모델로 수렴 예정.
