# 외부 연동 · 의도적 보류

버전: 0.1 · 2026-07-28 · rentsafe-pro

아래 항목은 **미구현이 아니라 의도적 보류**다. Cursor/시연 브랜치는 stub·소프트 패스를 유지하고, **실연동은 담당자가 별도 통합**한다. PASS/통신사 SDK·얼굴 매칭 엔진을 이 레포에서 붙이지 않는다. `DEMO_MODE` 동작도 바꾸지 않는다.

## 방향 구분 — 이 문서는 «아웃바운드»다

이 문서는 착한거래가 외부 서비스를 **가져다 쓰는** 보류 목록이다.
반대 방향 — 회원사가 착한거래를 **서비스로 쓰는** 요청은 `docs/MEMBER-ESIGN-REQUEST.md` 를 볼 것.
프리패스(freepasserp4)의 전자계약 연동 요구사항이 거기 있다.
그 연동의 선행 조건이 **아래 두 항목(휴대폰 본인인증·얼굴 실대조)** 이다 —
회원사 계약에는 주민등록번호가 들어가므로 본인확인이 mock 인 동안은 실데이터를 받을 수 없다.

## 보류 목록

| 항목 | 현재 상태 | 담당 |
|------|-----------|------|
| **휴대폰 본인인증** | stub (`lib/kyc/phoneProvider.js`) — 요청/검증 모두 mock 통과 | 담당자 실연동 예정 (PASS/통신사 등) |
| **얼굴 실대조** | 촬영·증빙(저장·콘솔 대조 UI)만 — **매칭 엔진 없음** | 담당자 연동 예정 |

## Cursor / 데모가 유지하는 것

- 신분증 촬영 플로우 (카메라 캡처 → 확인 → 다음)
- OCR 보조 (가능하면 필드 채움; 없어도 시연 진행)
- soft demo pass (빈 입력·느슨한 통과 — `DEMO_MODE` 정책 그대로)
- link-only 검증 상태 (증명서 파일·캡처 대체 제출 없음; 서버 기준 URL 확인)
